# 一番賞抽獎計算所

輸入剩餘抽數、目標賞與預計抽數，計算至少抽中一個目標賞的機率與預算。

線上版本：https://jwander0820.github.io/IchibankujiCalculator/

## 功能

- 超幾何分布機率計算
- 20%、50% 與自訂期望機率所需抽數
- 1–30 抽機率與預算地圖
- 依目前盤面進行不放回抽樣的互動撕籤模擬（支援拖曳與點擊撕開）
- 使用 `torn-ticket-cover.svg` 與 `torn-ticket-paper.svg` 渲染可撕面板及結果籤紙，不依賴點陣圖片
- 快速情境帶入（內建情境預設試抽 3 次）
- 將最多 8 個觀察 Set 保存在瀏覽器本機，優先顯示於快速帶入列
- 載入觀察 Set 後，後續盤面調整會自動回寫至該 Set
- 分享目前分析設定

每抽價格預設為 NT$335，可依實際售價自由調整。

## 網站圖示

圖示以朱紅色抽賞券、黃色票根及百分比符號結合「抽賞」與「機率計算」。首頁標題旁與桌面版主視覺使用同一份向量圖，手機版保留標題旁圖示。

- `public/icon.svg`：可編輯的向量原稿，同時作為現代瀏覽器的分頁圖示。
- `favicon.ico`：由向量原稿產生，包含 16、32、48 px，供其他瀏覽器使用。
- `public/apple-touch-icon.png`：由向量原稿產生的 180 px 圖示，供 iOS 加入主畫面使用。

修改原稿時，請同步重新輸出 ICO 與 PNG。所有圖示引用均使用相對路徑，支援 GitHub Pages 的儲存庫子路徑與自訂網域。
